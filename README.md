# Measuring App

GitHub Pages replacement build for the existing `maintenance-app` repository.

## Autosave

The current document is saved to browser storage after every field input, quick-fill toggle, row or column change, signature edit, and when Safari is backgrounded or closed. The storage key remains `maintenance-sheet-v1` so documents saved by the previous published version remain available.

Upload the contents of this folder to the root of the existing repository.
