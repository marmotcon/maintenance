# Measuring App

Compact iPad-optimized GitHub Pages replacement build for the `maintenance` repository.

## Changes

- Removed the 500 curb column.
- Removed the swale column.
- Removed all trial wording.
- Reduced table, header, toolbar, and input sizes to show more measurement columns on an iPad.
- Preserved quick-fill, sawcut autofill, signatures, Excel/PDF export, and immediate autosave.
- Older autosaved documents are migrated automatically so the removed columns do not reappear.
